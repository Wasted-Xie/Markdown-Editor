# 图表专项测试

本文件集中测试 Mermaid 的各类图表，用于排查渲染与主题切换问题。

## 流程图

```mermaid
flowchart TD
    Start([开始]) --> Check{文件已打开?}
    Check -- 否 --> Pick[选择文件夹]
    Pick --> Load[加载文件列表]
    Check -- 是 --> Edit[编辑内容]
    Load --> Edit
    Edit --> Auto{停止输入 1.2s?}
    Auto -- 是 --> Save[(写回磁盘)]
    Auto -- 否 --> Edit
    Save --> Done([完成])
```

## 时序图

```mermaid
sequenceDiagram
    autonumber
    participant App as 应用
    participant API as Tauri API
    participant FS as 文件系统
    App->>API: list_dir(root)
    API->>FS: read_dir
    FS-->>API: 目录项
    API-->>App: DirNode[]
    App->>API: read_file(path)
    API-->>App: 文本内容
```

## 状态图

```mermaid
stateDiagram-v2
    [*] --> 未打开
    未打开 --> 编辑中: 打开文件
    编辑中 --> 已修改: 输入
    已修改 --> 保存中: 防抖触发
    保存中 --> 编辑中: 写入成功
    保存中 --> 冲突: 外部修改
    冲突 --> 编辑中: 保留本地
    冲突 --> 编辑中: 重新加载
```

## 类图

```mermaid
classDiagram
    class Editor {
        +string value
        +onChange(text)
        +scrollToLine(line)
    }
    class Preview {
        +string html
        +renderMermaid()
    }
    class FileTree {
        +string root
        +openFile(path)
    }
    Editor --> Preview : 内容变化
    FileTree --> Editor : 选择文件
```
